The file annotations.csv contains graphemes from eight writing systems: Cyrillic (Uppercase), Greek (Uppercase, lowercase), Hebrew, Roman (Uppercase, lowercase), Tifinagh, Burmese, Malayalam, and Telugu. Although multiple possible allographemes might exist for each grapheme (such as the single- and double-story a), and each allographeme may be annotated in multiple ways, the annotation here has used only one annotation per grapheme.
